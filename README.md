# Mis Entregables

Página web para organizar y acceder rápidamente a los archivos entregables de cada módulo del curso.

## Propósito

Evitar crear un repositorio Git por cada actividad entregable. En vez de eso, tener todo en un solo lugar: una página web local donde están todos los archivos agrupados por módulo, semana y tipo (tareas, pruebas de desempeño, notas).

## Estructura

- **Python** - Semana 1, 2, 3 + Prueba de Desempeño + Notas
- **HTML y CSS** - Semana 1, 2, 3 + Prueba de Desempeño + Notas
- **JavaScript** - Semana 1, 2, 3 + Prueba de Desempeño + Notas
- **Base de datos** - Semana 1, 2, 3 + Prueba de Desempeño + Notas

## Cómo usar

1. Abre `index.html` en tu navegador
2. Navega entre módulos usando el panel izquierdo
3. Para modificar los archivos disponibles, edita el HTML y cambia los enlaces `href`
4. Los archivos deben estar en su respectiva carpeta
